# Emeraude Deconstruction

Deconstruct ships and carts with the hammer (middle click), like any other build piece. The materials are returned.

The game already knows how to remove a ship or a cart, but the option is turned off for them. This mod turns it back on, with safeguards:

- nobody is aboard the ship;
- nobody is pulling the cart;
- nobody has the cargo open;
- the cargo is empty (every cargo, for modded ships with several);
- nothing is built on the ship (with Build On Ship: chests, beds, portals… must be removed first).

The usual rules still apply: a crafting station in range and no private area. When the removal is refused, a message tells why.

When a ship is destroyed, by monsters or with the hammer, its materials are put in a floating cargo crate, like its cargo, instead of scattering on the water.

## Installation

Install it on **every player's game**: the hammer runs on the player's side. Installing it on the server too is harmless.
