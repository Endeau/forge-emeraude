# Changelog

## 1.2.0 — 2026-11-23
- A destroyed ship (by monsters, or removed with the hammer) leaves its materials in a floating cargo crate, like its cargo, instead of scattering them (nails used to sink).
- A refused removal always tells why (someone aboard, cargo open, cargo not empty, cart pulled, something built on the ship) instead of the game's generic message.

## 1.1.0 — 2026-11-23
- A ship can't be deconstructed while something is built on it (Build On Ship: chests, beds, portals…), with a message telling to remove it first.
- Every cargo of the ship must be empty, not only the first one (modded ships such as Sækonungr Ships).

## 1.0.0 — 2026-11-13
- Ships (raft, karve, longship, drakkar) and carts can be deconstructed with the hammer, like any other build piece.
- Blocked while a player is aboard, pulling the cart or using the cargo, or while the cargo is not empty.
