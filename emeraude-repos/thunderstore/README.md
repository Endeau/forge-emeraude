# Emeraude Repos

The Rested buff lasts **1.5 times longer**. In the base game it lasts 5 minutes plus 1 minute per comfort level above the first; with this mod, 7 min 30 s plus 1 min 30 s per level. Comfort 10 gives 21 min instead of 14.

## Configuration

`BepInEx/config/emeraude.repos.cfg`: `Rested.DurationMultiplier` (1.5 by default).

## Installation

Install it on **every player's game**: each game computes its own Rested buff. The server doesn't need it.
