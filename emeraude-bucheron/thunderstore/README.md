# Emeraude Bucheron

Chopping trees pays off: every **large tree** you fell now always drops

- **1 to 3 resin** (or what the game rolled, if it rolled more), for every tree that can drop resin;
- **its seeds** at their usual amount: 2–3 beech seeds, 1–2 birch seeds, 2–3 acorns, 1 fir cone, 1 pine cone. You can always replant what you cut.

In the base game a felled tree has a 50% chance to drop 1 to 3 extras among seeds, feathers and resin: a birch gives less than one seed on average. Feathers and wood are unchanged. Small trees, stumps and logs are unchanged.

## Installation

Install it on **every player's game and on the server**: the tree drops its loot on the game of whoever owns it. Jötunn refuses to connect players who don't have the same version as the server.
